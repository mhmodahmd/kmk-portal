## 0. الهيكل العام (Shell)

| الشاشة | الوصف | |
|---|---|---|
| تسجيل الدخول | اسم المستخدم وكلمة المرور، "تذكّرني على هذا الجهاز"، نقش البكسل والشعار | ✅ |
| تغيير كلمة المرور الإجباري | عند أول دخول أو بعد إعادة التعيين | ✅ |
| **الرئيسية** | بطاقات حسب الدور: حضور اليوم، عهدتي، بانتظار موافقتي، مهامي، تنبيهات المستندات، ملخص مالي | 🆕 |
| **صندوق الموافقات** | كل الطلبات المنتظرة من كل الوحدات، مع تصفية حسب الوحدة والموافقة السريعة | 🆕 |
| الإشعارات | لوحة منسدلة من الجرس ✅ (0.8.0) · الصفحة الكاملة مؤجلة | ✅ جزئياً |
| البحث الشامل | Ctrl+K: موظفون، عملاء، عهد، مهام، فواتير، صفحات | مؤجل |
| ملفي | بياناتي، كلمة المرور، توقيعي، الأجهزة المحفوظة، الوضع الليلي | ✅ جزئياً |
| صفحة توقيع المدير | صفحة عامة برابط مؤقت لتوقيع سند أو كشف | ✅ |

**التنقل:** قائمة جانبية داكنة مقسّمة إلى مجموعات (الموظفون · العمل · المالية · النظام). على الجوال: شريط سفلي بأربعة أزرار حسب الدور + «المزيد» (الرئيسية، الحضور، المهام، الموافقات؛ ومن لا يملك وحدة يحل محلها العهدة أو العملاء أو ملفي).
