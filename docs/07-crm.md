## 3. ما يُنقل إلى البوابة وكيف
| السابق | في البوابة |
|---|---|
| العملاء + جهات الاتصال | وحدة العملاء `crm` (ملف `KMK-CRM`) |
| مراحل المسار | تُنقل كما هي ويُحسب منها «المسار» |
| المشاريع | **سجل المشاريع الموحد** في العملاء، ويصبح هو قائمة المشاريع التي تختارها العهد والمهام (بدل القائمة المنفصلة في العهد) |
| الدفعات | دفعات المشروع (محصّلة/مجدولة) مع رقم الفاتورة والطريقة والمستلم. الحساب المالي يُحسب ولا يُخزن |
| العروض | عروض الأسعار؛ قبول العرض يُنشئ مشروعاً مرتبطاً |
| الأنشطة | سجل التواصل (اجتماع، مكالمة، زيارة، متابعة، واتساب) على خط زمني للعميل |
| المهام (238) | **وحدة المهام الموجودة** مرتبطة بالعميل أو المشروع (يُضاف الربط `client`/`project`)، والمتكررة شهرياً تبقى متكررة |
| المستندات (روابط) | روابط على العميل أو المشروع، والملفات الجديدة على Drive كما في العهد |
| المستخدمون | يُربطون بحسابات البوابة؛ من ليس له حساب يُنشأ له أو يُنسب لمدير النظام |
| الإشعارات | إشعارات البوابة (الجرس والبريد) |

## 4. التطوير المقترح
1. **صفحة العميل الشاملة:** بياناته، جهات الاتصال، المشاريع، الدفعات والمتبقي، العروض، الأنشطة، المهام، والمستندات في خط زمني واحد، وزر «مهمة جديدة» و«نشاط جديد».
2. **نوع الفوترة للمشروع:** «عقد ثابت» أو «اشتراك/مفتوح» حتى لا يظهر المتبقي سالباً؛ المشاريع التسعة بلا عقد تُنقل «مفتوحة» وتظهر لك في قائمة مراجعة.
3. **تذكير التحصيل:** الدفعة المجدولة تظهر في الرئيسية وتُرسل إشعاراً للمسؤول قبل موعدها وعند تأخرها.
4. **المتابعة الآلية:** نشاط «متابعة» بتاريخ قادم يُنشئ مهمة للمسؤول تلقائياً (كما نصت الخطة).
5. **ربط العهد بالمشاريع:** مصروفات العهدة تختار المشروع من السجل الموحد، فتظهر تكلفة المشروع بجانب إيراده.
6. **التقارير الأساسية:** العملاء، المشاريع والتحصيل، العروض ونسبة القبول، نشاط الفريق، مع تصدير Excel وطباعة.
7. **الصلاحيات:** «مبيعات» يرى عملاءه وما أُسند إليه، و«مدير مبيعات» يرى الكل (الأدوار الموجودة في `MODULES`)، والدفعات للمحاسب ومدير المبيعات.

### يؤجَّل (لا يُبنى الآن)
الرؤى الآلية وتقييم العملاء وتوقعات الإيرادات، ربط واتساب (رسالة واحدة مسجلة)، مفاتيح API والـ Webhooks، الأهداف (4 سجلات تُحفظ في النقل وتُبنى شاشتها مع المالية)، قوالب المشاريع.

## 5. النقل
- من ملف التصدير نفسه (لا اتصال بـ Supabase)، بمعرّفات ثابتة وإعادة تشغيل آمنة كما في نقل العهد، وتقرير مطابقة لكل مشروع (العقد، المحصّل، المجدول).
- النظام السابق لا يُعدَّل، ويبقى يعمل حتى اعتماد البوابة.
